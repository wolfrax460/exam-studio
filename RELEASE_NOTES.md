# Exam Studio 0.2.4

## Updated desktop workspace

- Includes the refreshed sign-in, account creation and administration screens.
- Downloads future official installers automatically and checks their SHA-256 before showing the download. Open the downloaded installer when you are ready to update. Install version 0.2.4 once to enable this behavior.
- Provides Windows x64 setup and portable executables, Linux x64 AppImage, Debian package and ZIP, and macOS disk images for Apple silicon and Intel. The app requires macOS 13 Ventura or later.
- Includes the institution registration and approval preview, which is disabled by default.

The Windows executables are unsigned. The macOS apps use ad hoc signing and have no Apple notarization. Compare the SHA-256 of your download with `SHA256SUMS.txt` before opening it.

Existing accounts, library documents, and settings on the computer are kept in the Exam Studio data directory.
